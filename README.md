# Ritmo — protótipo de interface

Interface inicial para organizar tarefas, metas diárias e hábitos. A página roda localmente sem instalar dependências:

1. Baixe ou clone este repositório.
2. Abra `index.html` em um navegador moderno.

## O que já funciona

- Criar, concluir e excluir tarefas com dia, horário e nota.
- Criar metas diárias e registrar progresso com os botões + e −.
- Criar hábitos com data de início, acompanhar a contagem automática e reiniciar a contagem mantendo o histórico de reinícios.
- Filtrar tarefas e navegar pelas seções da interface.
- Guardar os dados no `localStorage` do navegador usado.

## Limite desta etapa

Este é um protótipo local. Os dados ficam apenas no navegador e não são compartilhados com o bot nem com outros dispositivos. Ainda não há login, banco de dados ou notificações do Discord. A próxima etapa será conectar a interface e o bot a uma API e a um banco de dados compartilhado.

A interface está em português e foi feita com HTML, CSS e JavaScript sem dependências de build.
